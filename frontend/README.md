# 세일즈맨 CRM 목업

Node.js 22.12 이상에서 다음 명령을 실행합니다.

```powershell
cd frontend
npm.cmd ci
npm.cmd run dev
```

터미널에 표시된 로컬 주소를 엽니다. 배포용 빌드는 `npm.cmd run build`로 생성합니다.

## 시연

1. 사이드바 문의함에서 검토 대기 수를 확인하고 메일을 열어 새 리드를 등록합니다.
2. 리드 상세 개요의 ‘다음 업무’에서 업무를 추가하고 다른 팀원에게 배정합니다.
3. 오른쪽 위 프로필 메뉴에서 배정받은 팀원으로 전환합니다. 홈에서 업무를 열어 상태를 완료로 변경합니다.
4. 홈에서 메일 템플릿을 만듭니다. 마이페이지에서 관련 리드를 골라 메일 초안을 만들고 템플릿을 적용합니다.
5. 팀 설정에서 공용 메일 연결 상태와 마지막 성공 시각을 확인합니다. 첫 실행에서는 가상 메일 한 건이 연결 상태에 맞춰 자동으로 수집되며 문의함에서 즉시 동기화도 할 수 있습니다.

샘플 데이터와 변경 사항은 현재 브라우저에 저장합니다. 데모 팀원 전환은 실제 인증을 대신하며, 공용 메일 수집과 개인 메일 초안은 로컬에서 시연합니다.

## 소스 구성

- `src/app`에 화면 경로, 공통 레이아웃, 상태 변경 진입점을 둡니다.
- `src/features`에 IA의 화면과 업무 기능을 둡니다.
- `src/domain`에 CRM 데이터 타입과 정렬, 상태 표시, 템플릿 치환 규칙을 둡니다.
- `src/data`에 샘플 데이터와 브라우저 저장 코드를 둡니다.
- `src/ui`에 색상 토큰과 공통 UI를 둡니다.
