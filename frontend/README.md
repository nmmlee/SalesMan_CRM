# bpocrm

Node.js 22.12 이상에서 다음 명령을 실행합니다.

```powershell
cd frontend
npm.cmd ci
npm.cmd run dev
```

터미널에 표시된 로컬 주소를 엽니다. 배포용 빌드는 `npm.cmd run build`로 생성합니다.

## 시연

1. 문의함에서 메일을 열고 기업과 담당자를 등록하거나 기존 항목에 연결합니다.
2. 기업·담당자 시트에서 검색하고, CSV 양식·업로드·다운로드를 사용할 수 있습니다. 담당자 CSV는 기업 정보를 먼저 등록한 뒤 업로드합니다. CSV는 UTF-8 형식으로 한 파일에 최대 1,000행을 등록할 수 있으며, 동일 식별 정보가 있으면 전체 업로드를 중단합니다.
3. 담당자 행을 열어 접촉 이력을 기록하고, 도입 의향을 확인하면 해당 담당자에서 리드를 등록합니다. 리드의 영업 단계를 `수주`로 변경하면 고객사 관리 목록에 표시됩니다. 진행을 중단한 리드는 담당자 상세 또는 리드 상세에서 사유를 입력해 로스트 처리할 수 있습니다.
4. 리드 상세 개요의 ‘다음 업무’에서 업무를 추가하고 다른 팀원에게 배정합니다.
5. 오른쪽 위 프로필 메뉴에서 배정받은 팀원으로 전환합니다. 홈에서 업무를 열어 상태를 완료로 변경합니다.
6. 홈에서 메일 템플릿을 만듭니다. 마이페이지에서 관련 리드를 골라 메일 초안을 만들고 템플릿을 적용합니다.
7. 팀 설정에서 공용 메일 연결 상태와 마지막 성공 시각을 확인합니다. 첫 실행에서는 가상 메일 한 건이 연결 상태에 맞춰 자동으로 수집되며 문의함에서 즉시 동기화도 할 수 있습니다.

샘플 데이터와 변경 사항은 현재 브라우저에 저장합니다. 데모 팀원 전환은 실제 인증을 대신하며, 공용 메일 수집과 개인 메일 초안은 로컬에서 시연합니다.

## 서버 연동

`VITE_CRM_MODE=server`로 배포하면 `api/index.ts`가 회원가입, 로그인 세션과 CRM 데이터 접근을 처리합니다. Supabase 연결 정보는 Vercel 서버 환경변수에만 저장합니다. 데이터베이스 교체와 Vercel 설정은 [배포 안내](../DEPLOYMENT.md)를 따릅니다.

## 소스 구성

- `src/app`에 화면 경로, 공통 레이아웃, 상태 변경 진입점을 둡니다.
- `src/features`에 IA의 화면과 업무 기능을 둡니다.
- `src/domain`에 CRM 데이터 타입과 정렬, 상태 표시, 템플릿 치환 규칙을 둡니다.
- `src/data`에 샘플 데이터, 브라우저 저장 코드와 서버 데이터 변환 코드를 둡니다.
- `api`에 Vercel 회원가입·로그인·CRM API를 둡니다.
- `src/ui`에 색상 토큰과 공통 UI를 둡니다.
